# Library Management System (JavaFX + SQLite)

A simple **Library Management** desktop application built with **Java 21**, **JavaFX**, and **SQLite**, using **Maven** for builds.  
The app uses a layered structure (`controller`, `service`, `model`, `database`, `util`) and includes **BCrypt** for password hashing.

This version includes copy-level accession tracking, improved issue/return workflows, richer book detail views, and enhanced reporting behavior.

---

## Tech Stack

- **Java**: 21
- **UI**: JavaFX (Controls + FXML)
- **Database**: SQLite (via `sqlite-jdbc`)
- **Security**: BCrypt (`jbcrypt`) for password hashing
- **Build Tool**: Maven
- **Packaging**: Maven Shade Plugin (fat JAR)

---

## Project Structure

Main entry point:

- `src/main/java/com/library/App.java`

Key packages:

- `src/main/java/com/library/controller` — UI controllers (JavaFX)
- `src/main/java/com/library/service` — business logic/services
- `src/main/java/com/library/model` — data models/entities
- `src/main/java/com/library/database` — DB connection / queries / DAO layer
- `src/main/java/com/library/util` — helper utilities

## Current Features

### Authentication

- Login with role-based users (e.g., Admin, Librarian)
- Password hashing with BCrypt

### Books

- Add/Edit/Delete books
- Clickable book title opens a **Book Details** dialog
- Details dialog includes:
	- horizontal summary info (author, class no, total, available)
	- copy availability sheet with accession no, status, issued-to, return date
- Accession workflow supports:
	- entering a single starting accession number
	- entering copy count
	- automatic generation of accession list (e.g. `1000` + `10` => `1000..1009`)
	- duplicate checks against both in-form list and database

### Members

- Add/Edit/Deactivate/Delete members
- Filters by course, intake, type, active/inactive
- Dynamic intake options (auto-generated by year)

### Issue / Return

- Find member and book before issue
- Choose exact physical copy from available copy dropdown
- If multiple members have same/similar name, selection dialog appears with:
	- name, member ID, type, department, intake, email, phone
- Return table auto-populates with currently issued books
- Return flow calculates overdue fine and processes return

### Dashboard & Reports

- Stats cards and charts (category, monthly issue/return, member distribution)
- Monthly activity Y-axis uses whole numbers (`0, 1, 2, ...`)
- CSV report generation:
	- issued books
	- overdue books
	- inventory
	- member list
	- monthly summary

## Setup & Run

### 1) Clone the repo
```bash
git clone https://github.com/shresthasameerman/library-management.git
cd library-management
```

### 2) Run with Maven (JavaFX plugin)
Your `pom.xml` is configured to run the app using JavaFX Maven Plugin with:

- Main class: `com.library.App`

Run:
```bash
mvn javafx:run
```

---

## Build

### Build a runnable (fat) JAR
This project uses the **Maven Shade Plugin** to create a fat JAR during `package`.

```bash
mvn clean package
```

After build, check `target/` for the generated JAR.

> Note: the repository currently includes a `target/` directory. Usually, `target/` is not committed to Git and is added to `.gitignore`.

## Database (SQLite)

This project includes SQLite support via:
- `org.xerial:sqlite-jdbc`

The DB setup/connection logic is expected inside:
- `src/main/java/com/library/database`

Core tables include:

- `users`
- `books`
- `book_copies` (physical copy per accession)
- `members`
- `issue_records`
